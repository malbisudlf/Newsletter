# Newsletter
Solo un documento para guardar el historial de mis newsletters

- `historial-briefings.json` — historial de briefings enviados (mejor esfuerzo: el
  contenedor de ejecución es efímero y el fichero no persiste entre ejecuciones).
- `prompts/briefing-diario.md` — texto de la rutina del briefing diario. Es una copia de
  referencia: el que se ejecuta de verdad es el que está guardado en la tarea programada,
  así que al cambiar este hay que pegarlo allí.
