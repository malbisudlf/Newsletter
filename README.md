# Newsletter
Solo un documento para guardar el historial de mis newsletters

- `historial-briefings.json` — historial de todos los briefings enviados, una entrada por
  fecha. La rutina lo actualiza directamente en `main` después de cada envío.
- `prompt-briefing-diario.md` — texto de la rutina del briefing diario. Es una copia de
  referencia: el que se ejecuta de verdad es el que está guardado en la tarea programada,
  así que al cambiar este hay que pegarlo allí.
